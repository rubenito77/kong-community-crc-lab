## Seguridad

No se almacenan claves, secretos ni tokens en Git, parámetros, PVC, evidencia o
logs de la Pipeline. Durante una inspección manual se mostró accidentalmente el
contenido Base64 de los campos del Secret. Los valores no se decodificaron ni se
incorporaron a este documento; la credencial aleatoria fue eliminada
inmediatamente durante el rollback.

No se debe inspeccionar un Secret mediante columnas que incluyan `.data`.
Se deben consultar únicamente metadatos y nombres de campos.
